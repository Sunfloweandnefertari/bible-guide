# 讲道风格提取规范（供分析 agent 使用）

> 目的：从转写稿中提取这位老师的**「说话方式」**，用于构建 `references/07-讲道风格.md`。
> 关键区分：提取 **HOW he teaches（怎么讲）**，不是 **WHAT he said（讲了什么内容）**。
> 内容会过时、换主题；说话方式是稳定的指纹。

## 一、提取维度（六个）

### 1. 表达 DNA（最核心）
- **口头禅与语气词**：统计并举例（呃/啊/嗯/OK/对不对/明白吗…），它们出现在什么位置
- **句式习惯**：先问后答？先结论后解释？爱用反问？爱用「即系…」类解释性重复？
- **称呼方式**：怎么称呼学员（点名直呼？「弟兄姊妹」？），怎么称呼神
- **确定 vs 谦和**：说话是斩钉截铁还是常留余地（「我觉得」「可能」）
- **幽默方式**：自嘲？调侃学员？谐音梗？举荒诞例子？
- **重复强调**：重要观点怎么强调（重复三次？换说法重述？）

### 2. 教学方法
- 怎么开场（唱歌？祷告？提问？分享近况？）
- 怎么引入主题（从生活切入？从问题切入？）
- **是否苏格拉底式**：提问的频率、提问后是否等待回应、怎么接住学员的回答
- 怎么引导读经（让学员自己读？带着找关键词？）
- 怎么收尾（祷告？总结？预告下次？）

### 3. 比喻与例证库
- 列出**所有**用过的类比/故事（如「虫变蝴蝶」「飞机为什么能飞」「妈妈和女儿像」）
- 每个标注：用来说明什么道理、取自什么来源（生活/科学/时事/个人经历）
- 特别注意：他偏爱从哪些领域取材（科学？物理？时事新闻？家庭？工作？）

### 4. 释经方式
- 讲一段经文时，他先做什么（读原文？问背景？找关键词？）
- 怎么处理难解处
- 怎么从经文过渡到应用
- 是否对比不同译本
- 是否引用原文（希腊文/希伯来文）

### 5. 互动与场域
- 怎么营造氛围（「我们很自由」「随你怎么叫」）
- 怎么回应学员的分享（肯定？追问？接住情绪？）
- 怎么处理跑题、沉默、争议
- 学员的名字出现频率（说明互动的亲密程度）

### 6. 主题与神学侧重
- 反复出现的主题（生命改变？灵与良知？诚实？）
- 神学词汇偏好（「生命」vs「得救」？「灵」？「神的形象」？）
- 强调什么、少讲什么
- 怎么处理科学与信仰（他似乎很爱用科学做护教）

## 二、输出格式（每个分析 agent 返回）

```
## 文件：<文件名>

### 口头禅实录（带原句）
- 「OK吗？」——用在讲解段落结束时，确认听众跟上。例：「…所以这个是神的工作，OK吗？」
- 「…」

### 典型句式
（3-5 个模式，每个配 1-2 个原句）

### 比喻/例证清单
| 比喻 | 用来说明 | 取材领域 |
|---|---|---|
| 虫变蝴蝶 | 生命有改变的可能 | 自然 |

### 教学方法观察
（开场/引入/互动/收尾的实际做法）

### 金句式的表达习惯
（他怎么把道理说得让人记得）

### 值得注意的独特之处
（与其他讲者不同的地方）
```

## 三、硬性要求
1. **必须引用原句**——不能只说「他爱用比喻」，要给出实际例子
2. **保留口语原貌**——不要美化、不要书面化，我们提取的就是他的口语特征
3. **标注 ASR 疑点**——转写有错的地方（同音字、粤语误识别）用 [?] 标注，不要自行「修正」成自己的话
4. **不评价神学对错**——只描述风格，不做神学判断
5. **发现矛盾保留矛盾**——不同场次表现不一致的地方如实记录
